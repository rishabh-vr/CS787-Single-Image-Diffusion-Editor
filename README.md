# CS787 — Single-Image Diffusion Editor

*Training-free single-image diffusion: reproduction, out-of-distribution study and baselines.*

Course project (CS787) built on **Qiu, Kutulakos & Lindell, *Efficient and Training-Free Single-Image Diffusion Models*** (arXiv:2606.04299; official code: [haojunqiu/efficient-SID-code](https://github.com/haojunqiu/efficient-SID-code), MIT).

What we do:
1. **Reproduce** the paper's closed-form, training-free single-image diffusion.
2. **Test it out of distribution:** floor plans, geometric patterns, circuit schematics, plus a controlled synthetic set.
3. **Compare** it against training-based baselines: SinDDM and DreamBooth-LoRA.

All GPU work runs on **free Google Colab**.

## Layout

```
src/sidx/core/       our re-implementation of the method (CPU or CUDA), checked against the official code
src/sidx/methods/    one interface for every generator: sid_core (ours), sid_official, dummy
src/sidx/data/       image descriptors (edge density, periodicity, patch rarity, ...)
src/sidx/runner.py   resumable, time-budgeted job runner
scripts/             run_queue.py, prepare_natural.py (data + manifests), check_equivalence.py,
                     make_notebooks.py
configs/jobs/        experiment job files (YAML)
data/manifests/      one CSV per image set: path, size, sha256, source, licence, descriptors
                     (the images themselves are third-party and not committed)
reports/             results that are small enough to commit (e.g. equivalence reports)
notebooks/           free-Colab drivers (generated by scripts/make_notebooks.py)
patches/sinddm_port/ our port of SinDDM to current PyTorch (resume, CPU/Colab support)
env/                 requirements for Colab and the local CPU environment
tests/               CPU tests (pytest)
docs/                technical notes and workflow
```

Third-party code (`efficient-SID-code`, `SinDDM`) is **not vendored**. The notebooks clone it at the audited commits recorded in `docs/technical_notes.md`.
